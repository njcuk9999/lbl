# PCA2D options

The options of the precleaning, as a wrap gives them in its `PCA2D` key
(`rparams['PCA2D'] = dict(n_star=1, n_earth=7)`) and as the PCA2D settings
tab lays them out. The table is read from the code itself (LBL's
`nominal.yaml` and the window's labels), so it is the one of the LBL you
run. The method, the files and the examples: [PCA2D](../PCA2D.md).
